Windows 11版本 26H1

Windows 11版本 26H1 是一个专用的 Windows 版本，旨在与设备制造商和芯片合作伙伴合作，支持下一代硬件创新。 此版本仅在 2026 年初上市的选定新设备上预安装，并特意将这些平台限定为范围。 

Windows 11，版本 26H1 不是功能更新
与年度 Windows 功能更新（例如版本 24H2 和 25H2）不同，Windows 11版本 26H1 不是通过Windows 更新提供的。 这意味着它不能作为就地更新安装在现有设备上。 Windows 11，版本 26H1 不适用于跨现有Windows 11生态系统的广泛部署。

对于 IT 管理员，Windows 11版本 24H2 和 25H2 仍然是企业部署的建议版本，无需对现有推出、更新或购买计划进行更改。 希望评估新硬件平台的组织可以选择采用版本 26H1，而不会影响其环境的其余部分。 有关详细信息，请参阅有关 Windows 11 版本 26H1 的注意事项。

生命周期
Windows 11版本 26H1 于 2026 年 2 月 10 日发布，遵循Windows 11服务时间线：

Windows 11 专业版：自发布日期起服务 24 个月。
Windows 11 企业版：自发布日期起服务 36 个月。
